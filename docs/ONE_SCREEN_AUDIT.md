## 审计口径

- 改造前后均检查 `1280x720` 与 `1366x768`。
- 自动验收同时覆盖 `1440x900`、`1920x1080`、`768x1024` 与 `390x844`。
- 参数数量包含情景、模式或政策选择；动态图数量按学生可切换的分析视角统计。
- 桌面端要求页面级纵向滚动与水平溢出均为 0；移动端由上方观察区和下方独立滚动参数区组成。
