# 操作手册

## 学生

### 课堂五步简版

1. 载入明确标注为虚构的教学示例，或导入自己采集的 CSV。
2. 检查样本、有效薪资、缺失薪资和技能字段，确认样本边界。
3. 记录平均薪资、中位薪资和前三项高频技能。
4. 进入一个推荐实验，使用一个教师预设，只改变一个参数并保存记录。
5. 生成包含样本证据、仿真机制和不能推出内容的课堂结论。

### 完整项目版

1. 下载 CSV 模板并完成导入前预览。
2. 补充、编辑样本，查看城市、学历、经验、技能和薪资分布。
3. 完成相关实验并保存基准、反事实、指标和解释。
4. 生成并修订七部分 Markdown 报告。
5. 导出 Markdown、HTML 或 JSON 作业数据包。

两种视图共用同一份本地数据，切换不会复制或清空样本。

## 文旅样本校准

选择文旅/会展研究对象并导入至少 10 条样本。校准区显示“可以校准”后，点击“保存校准参数到成渝实验室”。成渝页面会显示样本量、采集期、缺失率、模型版本和不确定性。修改样本后旧校准自动失效。

## 教师

1. 学生分别导出 JSON 作业数据包。
2. 打开报告工作台的“教师汇总”页签。
3. 一次选择多个匿名数据包。
4. 查看闭环完成率、步骤完成情况、常见缺失和解释规则分布。
5. 导出班级汇总 CSV。

汇总数据只存在当前教师浏览器，清空页面不会影响学生设备。

## 三种模式

- 教学：`/?mode=teaching#/`；桌面导航可开启“投影显示”。
- 竞赛：`/?mode=competition#/`；首页按 5 分钟路线演示。
- 匿名预览：`/?mode=anonymous#/` 只核查页面逻辑，不构成正式匿名部署。
- 匿名交付：使用 `npm run build:anonymous` 的构建产物，并发布到中性账号、仓库和域名。

## 常见问题

- 刷新后数据仍在：这是当前浏览器的 `localStorage`。
- 换电脑看不到记录：导出并导入 JSON 作业数据包。
- 在线接口失败：检查 `VITE_API_MODE` 和 `VITE_API_BASE_URL`；GitHub Pages 应使用 offline。
- 图表为空：等待页面计算完成；仍为空时刷新并查看浏览器控制台。
- CSV 乱码：使用 UTF-8 保存。
- 清空数据：系统会连续两次确认；先导出 JSON 作业数据包再操作。
