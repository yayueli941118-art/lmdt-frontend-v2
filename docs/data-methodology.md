# 数据方法

## 数据管道

```text
学生手工采集
→ 标准 CSV
→ 导入前预览
→ 字段与缺失校验
→ 样本覆盖说明
→ 薪资/城市/学历/经验/技能统计
→ 可解释参数校准
→ 成渝情景比较
→ 实验记录与报告
```

系统不抓取招聘平台。学生应记录招聘平台、采集日期、企业、岗位、行业、城市、薪资上下限、学历、经验、技能、用工形式、岗位链接或截图编号。

## 校验与清洗

- CSV 采用 UTF-8；模板包含 16 个固定字段。
- 导入前报告总行数、可导入行、有效/缺失薪资、技能词数和问题行。
- 薪资下限高于上限时调换并标记问题；只填写一端时以该值作为样本薪资。
- 技能关键词用中文分号等常见分隔符拆分，不自动推断缺失技能。
- 空岗位且空企业的行不导入；其他缺失项保留并明确显示。

## 统计口径

- 样本薪资取上下限中点；平均值、中位数、最高和最低均只使用有效薪资样本。
- 城市、学历、经验按原始分类计数。
- 技能 Top 10 为样本词频，不代表行业总体技能权重。
- 招聘样本是岗位广告样本，不是居民收入、就业人数或岗位存量调查。

## 校准与拒绝

成渝校准只在样本量、行业匹配、薪资完整度和技能字段达到门槛时启用。校准页面展示样本量、日期范围、平台/城市构成、缺失率、参数前后值、模型版本和不确定性。

修改研究对象或样本后，旧校准参数通过输入指纹自动失效，防止新样本继续使用旧参数。

## 隐私与多人课堂

数据保存在当前浏览器的 `localStorage`。不同学生的浏览器彼此隔离，不存在“所有人打开看到同一份实验记录”的问题。跨设备使用 JSON 作业数据包；教师汇总只使用系统生成的匿名编号，不推断姓名、学号或设备身份。

## 结果边界

没有抽样权重和总体框时，只报告样本数量、样本岗位热度、样本薪资区间、样本技能结构和相对情景变化。不得据此声称全行业需要多少人、政策将创造多少岗位或学生一定获得某份工作。
