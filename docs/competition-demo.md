# 竞赛展示导览

## 5 分钟路线

使用 `/?mode=competition#/` 进入竞赛版。

1. **0:00-0:45 教学痛点**：首页说明静态曲线难以同时看清参数、均衡与机制。
2. **0:45-2:00 理论转译**：打开劳动供给“替代效应主导”预设，展示 A-B-C 和 Hicks 补偿。
3. **2:00-3:15 数据应用**：打开“数字文旅升级”预设，说明招聘样本统计如何经过质量门槛校准情景参数。
4. **3:15-4:15 学习闭环**：记录基准、调整参数、记录反事实，提交学生解释并查看透明规则反馈。
5. **4:15-5:00 成果与证据**：在报告工作台展示 Markdown 草稿、匿名作业包和教师汇总。

## 三个预设

- 替代效应主导：工资提高后，固定偏好下劳动供给增加。
- 结构性失业冲击：技能错配上升使 Beveridge 曲线整体外移。
- 数字文旅升级：数字化提高数字营销、数据分析和智慧景区岗位相对热度。

每个预设页面都有恢复默认参数按钮。图表动画约 500 毫秒，首屏使用离线教学模型，不等待不存在的后端。

## 答辩边界

- 不宣称平台已自动接入实时市场数据。
- 不把招聘广告数当行业岗位总量。
- 不把 Oaxaca 不可解释部分等同于歧视。
- 不展示未经用户导入验证的班级人数或教学成效。
- “数字孪生”如被问及，应说明当前完成的是可追溯的样本校准情景链条，不是实时产业全量镜像。
