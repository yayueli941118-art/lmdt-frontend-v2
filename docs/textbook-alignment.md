# LMDT 教材对齐审计

## 使用边界

- 教材来源：用户提供的《劳动经济学（第三版）》扫描版，按章节拆分 PDF。
- 页码说明：`PDF页`指拆分文件中的页序，`教材页`指扫描页眉印刷页码。
- 系统定位：**AI劳动力市场分析、机制仿真与预测实验室**。页面结果按历史观测、用户导入、教学示例、教材机制、统计预测、情景推演和规则反馈分类，不把机制模拟表述为现实市场的精确预测。
- 结果来源分为：`教材机制模拟`、`用户导入样本统计`、`情景参数推演`。三类结果不能相互冒充。

## 横向一致性验收

1. 所有实验默认参数必须落在滑块刻度上。
2. 图表必须标注横轴、纵轴、单位和结果来源。
3. 页面默认实时更新；按钮仅作为“恢复教材基准”或显式运行命令。
4. 每个实验都提供“模型说明”，包含公式、变量、单位、来源、假设、适用范围和不能推出的结论。
5. 教学版、竞赛版、匿名版共用模型代码，只切换身份信息、引导层级和展示措辞。
6. GitHub Pages 默认使用离线教学模型，不向不可用的 localhost 静默请求。
7. 实验记录仅保存在当前浏览器；匿名汇总必须通过导出/导入完成，不伪造班级数据。
