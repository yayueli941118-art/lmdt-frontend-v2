# 教学设计

课程代码2132036，2学分，32学时（理论16、实践16），考核方式为考查。课程考核由课堂实践与过程证据10%、个人实践档案30%、小组综合项目30%、个人综合实践考查30%构成；本页后文的“评价建议”是单项作品量规，不是课程总评权重。

## 学习目标

1. 识别教材图形中的变量、约束、均衡点和前提。
2. 用参数变化解释曲线移动，而不是只背结论。
3. 用基准与反事实结果支持机制解释。
4. 采集并校验招聘样本，将统计证据与模型证据组合成报告。
5. 说明模型能解释什么、不能证明什么。

## 统一实验闭环

1. 初始预测：调参前写出方向判断。
2. 初始理由：写出公式、约束或机制依据。
3. 基准结果：保存当前参数和指标。
4. 反事实：只改变一个或一组明确参数。
5. 证据解释：引用至少一个指标，并写出因果机制。
6. 规则反馈：检查是否有预测、对比、数值证据和机制词。
7. 修改解释：根据透明规则修订，不由系统替学生生成观点。
8. 保存报告：写入当前浏览器并进入报告工作台。

学生在每个核心实验的任务抽屉中看到统一六步：先预测、只调一个参数、查看指定主图、记录至少两项基准与当前指标、按“前提—机制—结果—边界”解释、保存记录并提交。教师可使用教材基准、反常冲突、AI时代或现实流动三类预设；预设只写入真实模型参数，不提供写死结果。

## 课堂组织

- 基础任务：按教材预设复现图形与方向。
- 进阶任务：改变两个参数，辨别收入/替代、周期/结构等机制。
- 数据任务：小组采集招聘样本并解释数据覆盖和偏差。
- 汇报任务：用一张关键图、一条恒等式和一个边界说明完成答辩。

建议每组导出 JSON 作业数据包。教师在“教师汇总”页一次导入多个匿名包，查看步骤完成率、常见缺失项和规则得分分布。系统不提供虚构班级样本或预置教学成效。

报告工作台默认提供课堂五步简版：载入数据、检查质量、读取统计、完成一个仿真实验、写出结论。完整项目版继续提供CSV预览、全量图表、样本编辑、校准、实验记录、报告和导出。两种视图共用同一份本地数据。

## 课程思政融入

价值讨论放在经济机制之后，自然连接体面劳动、公平就业、技能提升、区域协调和共同富裕。页面使用“思考”“讨论”而不是面向评委的“课堂追问”，避免每个模块生硬重复。

## 评价建议

- 机制准确 30%：前提、变量和方向正确。
- 证据充分 25%：引用样本统计和仿真指标。
- 反事实设计 20%：参数变化清晰且可复现。
- 边界意识 15%：不把情景结果当现实预测。
- 表达与规范 10%：图表、来源、截图编号和报告结构完整。
