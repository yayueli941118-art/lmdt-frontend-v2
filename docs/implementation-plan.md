# 教材机制升级实施计划

## P0 可用性与可信度

- 修复滑块默认值与步长不一致。
- 修复要素配置路由默认标签和城市迁移页面布局。
- 将接口运行方式拆分为 `offline`、`online`、`auto`，GitHub Pages 默认离线。
- 统一版本号、站点图标、页面定位和结果来源提示。
- 建立 Vitest、基础模型不变量测试和 GitHub Actions。

## P1 核心模型

- 第二章：固定偏好劳动供给、严格希克斯补偿、图2-9/2-10/2-11。
- 第三章：统一 CES 生产函数、VMP、市场反馈、长期成本最小化与弹性。
- 第四章：教育与培训年度现金流、NPV、IRR、回本期。
- 第五章：带就业概率和贴现率的迁移 NPV。
- 第七章：实际 OLS 与 Oaxaca 分解。

## P2 教学闭环与展示

- 每页加入模型说明和实验记录。
- 报告工作台区分样本统计与仿真记录，支持匿名包导入导出。
- 三种模式共用功能，匿名构建扫描身份信息。
- 完成桌面与移动端截图检查、构建检查和路由冒烟检查。
