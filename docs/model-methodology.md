# 模型方法与模型卡

## 共同约定

- 模型版本：`2.1.0`；领域模型的细分版本显示在实验记录中。
- 计算目的：机制解释、反事实比较和敏感性分析。
- 默认参数：为课堂图形可读性设置的教学情景，不是地区实证估计。
- 结果来源：教材公式、教学情景参数、用户导入数据、数据校准结果。
- 不能推出：具体个人决策、企业招聘量、地区失业率、产业岗位总量或政策因果效果。

每个实验页的“模型说明”统一列出公式、变量与单位、默认参数依据、来源、假设、适用范围、模型版本和不能推出的结论。

## 劳动供给

- 模型：固定偏好的 Stone-Geary 效用
  `U=(R-R0)^beta(C-C0)^(1-beta)`，预算约束 `C=V+W(T-R)`。
- 变量：闲暇 `R`（小时）、工作 `T-R`（小时）、消费 `C`（元）、非劳动收入 `V`（元）、工资 `W`（元/小时）。
- Hicks 补偿：在新工资下用支出函数求达到原效用所需的补偿收入。
- 验收：点在预算线上；补偿点效用等于原效用；替代效应加收入效应等于总效应；工资变化不改变偏好参数。

## 劳动需求

- 生产函数：`Q=A[aK^rho+(1-a)L^rho]^(1/rho)`，`rho=(sigma-1)/sigma`。
- 短期：资本固定；由生产函数解析计算 `MPL`，`VMP=P*MPL`；完全竞争时用 `VMP=W` 定位用工点。
- 市场反馈：产品需求弹性和价格反馈共同改变产品价格，不使用任意 VMP 位移。
- 长期：按给定产量最小化成本；最优点满足 `MRTS=W/R`。
- A-B-C：工资变化后的纯要素替代与产量规模调整分开计算。

## 人力资本

- 工资路径：`ln(W)=a+bS+cX+dX^2`，只负责构造教学工资轨迹。
- 现金流：教育期间计入直接成本和放弃的对照工资；毕业后计入选择组与对照组工资差。
- 指标：`NPV=sum(CF_t/(1+r)^t)`；IRR 由数值求根获得；回收期由累计贴现现金流首次非负确定。
- 培训：一般培训和特殊培训分别改变劳动者/企业成本承担与工资收益分享。
- 边界：信号理论是竞争性解释，不能从工资曲线单独识别。

## 劳动力流动

- 公式：`NPV=-C0+sum[(p*DeltaW_t-C_t)/(1+r)^t]`。
- 成本：一次性搬迁、逐年心理适应、可选配偶收入损失。
- 收益：月工资溢价转年收入，乘目标地就业概率，可设置增长率。
- 指标：NPV、IRR、回收年龄、最低工资溢价门槛、贴现率敏感性。

## 工资理论

- 工资分布：1000 个确定性合成样本，只用于说明分位数和参数变化。
- 效率工资：工资相对参考工资影响努力/留任指数。
- 补偿性差异：风险和不便程度对应补偿工资要求。
- 激励工资：基础工资、绩效占比和目标完成度共同决定总报酬。
- 无来源的行业、地区、性别和所有制乘数均标注为教学情景参数。

## 劳动力市场歧视

- Becker：雇主感知工资 `W*(1+d)`，劳动需求按用户选择的弹性响应。
- 统计性歧视：评价生产率 `lambda*个体信号+(1-lambda)*群体先验`；群体先验不等于个体真实生产率。
- Oaxaca-Blinder：对两组合成输入实际估计明瑟 OLS。教材模式使用两重分解，扩展模式使用三重分解。
- 会计恒等式：总差距等于禀赋效应、系数效应及可选交互效应之和。
- “不可解释部分”可能包含歧视，也可能包含遗漏变量、样本选择和模型设定影响。

## 收入分配

- 数据：400 个教学型合成收入观测，不称为居民调查数据。
- Lorenz：排序后计算累计人口和累计收入，强制经过 `(0,0)` 与 `(100,100)`，不用平滑插值。
- Gini：由排序收入的离散公式计算，范围为 0 至 1。
- 再分配：高于均值部分按强度缴款，按低于均值的缺口比例转移；缴款总额等于转移总额，财政净成本为 0。

## 失业、搜寻与匹配

- 存量流量：就业 `E`、失业 `U`、非劳动力 `N` 通过月度流率转换。
- 搜寻：保留工资受救济、搜寻成本、预期报价和等待偏好影响。
- DMP：`M=mU^alpha V^(1-alpha)`；风险率转换为期间概率 `1-exp(-hazard)`。
- Beveridge：基准和当前曲线均由分离率、匹配效率和稳态条件生成；需求冲击沿曲线移动，错配/效率冲击移动整条曲线。
- 最低工资：显示 Kaitz 指数、劳动需求弹性假设与结果区间，不引用无来源国家基准。

## 成渝文旅

- 未校准时：城市、业态和政策权重均为教学情景参数，输出“样本岗位热度指数（基准=100）”。
- 校准门槛：至少 10 条有效样本；薪资缺失率不高于 30%；研究对象或多数样本匹配文旅/会展；存在技能关键词。
- 校准参数：样本薪资中位数作为薪酬参考；数字技能词频映射到数字化指数。
- 不确定性：由样本量和薪资缺失率构造教学区间，明确不是抽样统计置信区间。
- 边界：招聘广告数量不等于社会真实岗位需求，政策得分不等于真实政策效果。
